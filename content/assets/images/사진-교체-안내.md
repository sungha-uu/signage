# 대시보드 음식 사진 관리 목록

대시보드에서 한 번이라도 사용한 음식 사진은 계절 메뉴 교체를 위해 삭제하지 않고 이 폴더에서 계속 보관합니다. 실제 노출 사진은 `content/menu-data.js`의 `gallery` 항목에서 선택합니다.

## 현재 사용 중

| 파일명 | 사용 위치 | 화면 보정 |
|---|---|---|
| `mandu-bibim.png` | 대표 세트 사진, 영상 포스터 | 대표 카드 전용 구도 |
| `tangsuyuk.jpeg` | 상단 옛날 탕수육 | 중앙 150% 확대 |
| `fishcake-generated-v2.png` | 상단 콩나물어묵 | 중앙 112% 확대, 아래 2.5% 이동 |
| `pot-udon-no-seaweed.png` | 상단 김가루 없는 냄비우동 | 중앙 103% 확대, 아래 1.5% 이동 |

## 교체용으로 보관

| 파일명 | 용도 | 비고 |
|---|---|---|
| `cold-noodle.png` | 여름철 냉메밀 복원용 | 메뉴 데이터에 냉메밀과 여름 한정 태그를 함께 복원 |
| `pot-udon.jpg` | 냄비우동 원본 | 보정 전 고해상도 원본 |
| `pot-udon-with-seaweed.png` | 김가루 있는 냄비우동 | 직전 대시보드 사용본, 중앙 104% 확대용 |
| `pot-udon-retouched-v2.png` | 김가루 있는 냄비우동 이전 파일명 | 기존 참조와 변경 이력 보존 |
| `fishcake.png` | 콩나물어묵 이전 사진 | 교체 이력 보존 |

계절 사진을 바꿀 때는 파일을 덮어쓰거나 삭제하지 말고 `gallery`의 경로만 변경합니다. 브라우저 캐시 방지를 위해 경로 뒤의 `?v=날짜-차수`와 `index.html`, `board.html`의 버전값도 함께 갱신합니다.

촬영·생성 사진은 음식과 그릇을 중앙에 두고 가장자리 바깥에 약간의 테이블 여백을 남깁니다. 화면별 확대와 위치 조정은 `src/styles.css`의 `.static-photo--* img` 규칙으로 관리합니다.
