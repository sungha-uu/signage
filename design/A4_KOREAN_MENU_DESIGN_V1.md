## 2. 생성 구조와 배율

`print/a4.html`은 3508×2480px 고정 캔버스를 만들고, 내부 iframe에서 TV 1페이지를 1920×1357px 뷰포트로 다시 렌더링한다. iframe 전체를 다음 배율로 확대한다.

```text
scale = 3508 / 1920 = 1.8270833333333334
iframe CSS size = 1920 × 1357.35px
output = 3508 × 2480px
transform-origin = left top
```

내부 좌표를 출력 좌표로 바꾸는 공식은 다음과 같다.

```text
outputX = innerX × 1.8270833333333334
outputY = innerY × 1.8270833333333334
outputW = innerW × 1.8270833333333334
outputH = innerH × 1.8270833333333334
```

1920×1080 TV 화면을 비례 확대하거나 세로로 늘리면 안 된다. iframe 높이를 1357.35px로 먼저 바꿔 CSS Grid가 A4 비율에서 다시 계산되게 해야 한다.

## 10. 폰트와 자산

- 기본 폰트: `PretendardVariable.woff2`
- fallback: `Noto Sans KR`, `Malgun Gothic`, `Apple SD Gothic Neo`, sans-serif
- 캡처 전에 `document.fonts.ready` 완료 필수
- 로고, 음식 사진, 아이콘은 커밋 `2c571a657dd60c0306f3648455f12368b42ad9d8`의 자산을 기준으로 한다.
- 승인 PNG 자체가 최종 시각 기준이며, 자산 교체 시 동일 디자인으로 간주하지 않는다.

## 11. 재생성 및 검증

승인 당시 커밋에서 다음 명령을 실행하면 승인 PNG와 바이트 단위로 동일한 파일이 생성된다.

```powershell
node scripts/export-a4.cjs --version-1-preview --ko-only
```

필수 검증:

1. 크기 3508×2480px
2. RGB
3. pHYs 11,811px/m
4. SHA-256 `855324EA2EC84C938A7F2164E231F3C1CEA9D39D17ED1CC845AF6BC0E2B487E9`
5. 빈 외곽 여백 없이 전체 캔버스 사용
6. 세 하단 카드 높이 동일
7. 사진 순서와 crop 동일
8. 가격에 `원` 포함

## 12. 다른 출력 크기로 변환

같은 A계열 가로 비율에서는 `s=min(newWidth/3508,newHeight/2480)`을 모든 좌표·글자·선·반경에 동일하게 곱한다. 비율이 다른 용지에서는 3508×2480 결과를 비균등 확대하지 말고, 먼저 내부 iframe 높이를 `newHeight/(newWidth/1920)`으로 계산한 뒤 CSS Grid를 다시 렌더링해야 한다.
