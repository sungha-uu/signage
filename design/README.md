# 메뉴판 V1 디자인 명세

- `TV_MENU_DESIGN_V1.md`: GitHub Pages와 Windows EXE의 TV 메뉴판 1·2페이지
- `A4_KOREAN_MENU_DESIGN_V1.md`: A4 가로 한국어 출력물
- `A4_FOREIGN_MENU_DESIGN_V1.md`: A4 가로 영어·중국어 출력물
- `*_METRICS_V1.json`: Chromium이 계산한 실제 좌표와 스타일 전수 측정값
- `scripts/capture-design-metrics.cjs`: 측정 JSON 재생성 도구

문서와 JSON이 다르면 JSON과 실제 V1 소스(`src/styles.css`, `src/app.js`, `print/*`)를 우선한다.
