# 섹시한 꾼만두 TV 메뉴판 디자인 명세 V1

이 문서는 `https://sungha-uu.github.io/signage/`에서 보이는 최종 TV 메뉴판 V1을 다른 작업자가 동일하게 재구현할 수 있도록 만든 고정 명세다. 모든 좌표는 특별한 언급이 없으면 **1920×1080 CSS 픽셀, 브라우저 배율 100%, devicePixelRatio 1** 기준이다. 소수점 `0.016px` 이하는 CSS Grid의 분수 픽셀 반올림으로 허용한다.

정확한 요소별 `x/y/width/height`, 계산된 글꼴·색상·그림자 값은 같은 폴더의 `TV_MENU_METRICS_V1.json`에 기록되어 있다. 명세를 갱신할 때는 `scripts/capture-design-metrics.cjs`를 실행해 JSON을 다시 생성한다.

## 1. V1 고정 조건

- 기준 페이지: `board.html?v=20260810-88`
- 기준 화면: 1920×1080, 16:9 가로형
- 화면 수: 2개
- 1페이지: 대표 세트/사진 3장/만두·별미·면 전체 가격표
- 2페이지: 왼쪽 메뉴판 50%, 오른쪽 영상 50%
- 기본 웹 동작: 버튼으로만 페이지 전환, 영상 수동 재생
- EXE 동작: 1페이지 30초 → 2페이지 자동 전환 및 영상 자동 재생 → 영상 종료 후 1페이지 복귀
- EXE 계절 효과: 없음
- 페이지 전환 효과: `.72s cubic-bezier(.22,.7,.2,1)`, 아래 16px에서 올라오며 opacity 0→1
- 데이터 원본: `content/menu-data.js`

- 외부 프레임/축소: `index.html`, `src/frame.css`, `src/frame.js`

## 2. 좌표계와 화면 축소 규칙

`index.html`은 1920×1080 고정 무대를 화면 중앙에 배치한다. 실제 화면이 `W×H`이면 다음 값을 사용한다.

```text
scale = min(W / 1920, H / 1080)
outputWidth  = 1920 × scale
outputHeight = 1080 × scale
offsetX = (W - outputWidth) / 2
offsetY = (H - outputHeight) / 2
```

모든 내부 픽셀값에는 `scale`을 곱하고 `offsetX`, `offsetY`를 더한다. 레이아웃 재배치는 하지 않는다. 휴대폰에서도 동일한 가로형 무대를 축소해 표시한다.

## 8. 태그와 서브 텍스트 최종 규칙

- 1페이지와 2페이지의 메뉴 리스트 상단 padding은 0px이다.
- 메뉴 카드 하단 padding은 2px이다.
- 인기/여름 태그는 모든 페이지에서 행 상단 기준 3px 아래다.
- 태그 때문에 메뉴명의 시작 x가 밀리지 않는다. 태그는 absolute 배치한다.
- 서브 텍스트는 행 아래 선에서 .5px 위, 메뉴명 시작점보다 오른쪽 5px에 둔다.
- 서브 텍스트가 없는 행도 동일한 행 높이를 유지한다.

## 11. 재현 절차

1. `content/menu-data.js`의 메뉴 순서와 문구를 위 표와 일치시킨다.

5. 생성된 `TV_MENU_METRICS_V1.json`과 기준값을 비교한다.

## 12. A4로 변환할 때의 원칙

TV 디자인을 A4에 사용할 때 16:9 캔버스를 단순 확대하면 A4 가로 비율과 맞지 않는다. 한국어 A4 V1은 폭 1920px을 유지하고 높이를 1357.35px로 늘려 1페이지를 재렌더링한 뒤 1.8270833333배 확대한다. 자세한 변환식은 `A4_KOREAN_MENU_DESIGN_V1.md`를 따른다.
